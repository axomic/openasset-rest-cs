# openasset-rest-cs (deprecated)

> [!WARNING]
> **This library is deprecated and no longer supported.**
>
> It is not maintained, will receive no further updates or fixes, and should not be used in new work.

This repository contained a C# client library and sample code for the OpenAsset REST API v1. It is kept online for reference only.

## What to use instead

Integrate directly against the OpenAsset REST API using the HTTP client of your choice.

- **API reference:** https://developers.openasset.com/
- **Guidance on building custom integrations:** [Developing custom integrations using the OpenAsset REST API](https://success.openasset.com/en/articles/3122502-developing-custom-integrations-using-the-openasset-rest-api)

## Support

We are unable to provide support for this library. For questions about the REST API itself, please contact OpenAsset support or visit https://www.openasset.com.
